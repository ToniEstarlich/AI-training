# AI Training

A practical learning workspace for developing the foundations of AI Engineering.

The goal is to understand how modern AI systems work by building five small projects before combining the knowledge into a larger project: **Beehive**.

## Learning Roadmap

| Project | Subject | Objective |
|---|---|---|
| 01 | MCP Calculator | Connect AI models to external tools using Model Context Protocol. |
| 02 | RAG PDF Assistant | Retrieve information from documents and provide context to an AI model. |
| 03 | Memory Assistant | Store and retrieve conversation and project context. |
| 04 | Evals Testing | Evaluate AI answers, accuracy, reliability and performance. |
| 05 | AI Harness | Coordinate models, tools, context, memory and execution. |

## Technology Stack

- Python
- Ollama
- Local Large Language Models (LLMs)
- Model Context Protocol (MCP)
- Retrieval-Augmented Generation (RAG)
- Git and GitHub
- FastAPI (where needed)

## Development Environment

- Windows
- Python 3.13
- Visual Studio Code
- PowerShell
- Ollama

We aim to experiment with local AI models wherever practical and minimise external API costs during learning.

## Learning Workflow

Each project follows the same development workflow:

1. Folder structure
2. Files and their responsibilities
3. Libraries and dependencies
4. Functions and how they communicate
5. Implementation and code
6. Frontend (where appropriate)

The emphasis is on understanding the architecture, not simply copying code.

## Final Objective: Beehive

The knowledge gained through these projects will contribute to **Beehive**, an AI workforce platform designed around a central AI orchestrator called the Queen.

The Queen will coordinate specialised AI workers and use shared capabilities:

- MCP: external tools and integrations
- RAG: knowledge retrieval
- Memory: user and project context
- Evals: quality and reliability evaluation
- Harness: orchestration and execution
